# Google 로그인 켜기

게임의 "로그인" 버튼은 배포할 때 **Google OAuth 클라이언트 ID**가 들어가야 나타납니다. ID가 없으면 버튼이 숨고, 나머지는 지금처럼 이 브라우저에만 저장됩니다.

이 ID는 비밀이 아닙니다. 페이지에 그대로 들어가는 공개 값이라 저장소 **변수(Variables)**에 넣습니다. 시크릿에 넣을 필요가 없습니다.

준비물은 Google 계정 하나이고, 비용은 들지 않습니다. 10분쯤 걸립니다.

## 1. Google Cloud 프로젝트 만들기

1. <https://console.cloud.google.com/> 에 로그인합니다.
2. 위쪽의 프로젝트 선택 → **새 프로젝트**를 누르고, 이름(예: `very-tactical-chess`)을 넣어 만듭니다.
3. 만든 프로젝트가 위쪽에서 선택되어 있는지 확인합니다.

## 2. Google Drive API 켜기

1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**로 갑니다.
2. `Google Drive API`를 찾아 **사용**을 누릅니다.

게임은 Drive 전체가 아니라 **앱 전용 숨은 폴더**(appDataFolder)만 씁니다. 이 폴더는 Drive 화면에도 보이지 않고, 이 게임 말고는 아무도 열 수 없습니다.

## 3. 로그인 화면 설정 (Google 인증 플랫폼)

예전 이름은 "OAuth 동의 화면"입니다.

1. 왼쪽 메뉴에서 **Google 인증 플랫폼**(Google Auth Platform)으로 갑니다. 처음이면 **시작하기**를 누릅니다.
2. **앱 정보**: 앱 이름(예: `아주 전략적인 체스`)과 사용자 지원 이메일을 넣습니다.
3. **대상(Audience)**: **외부(External)**를 고릅니다.
4. **연락처 정보**: 내 이메일을 넣고 정책에 동의한 뒤 **만들기**를 누릅니다.
5. **데이터 액세스(Data Access) → 범위 추가 또는 삭제**에서 다음 두 범위를 넣고 저장합니다.
   - `.../auth/drive.appdata`: 앱 전용 폴더 읽고 쓰기 (민감하지 않은 범위)
   - `email`: 누가 로그인했는지 버튼에 보여 줄 이메일 (민감하지 않은 범위)
6. **대상(Audience)**에서 게시 상태를 **프로덕션으로 푸시**(Publish app)합니다.
   - "테스트" 상태로 두면 직접 등록한 테스트 사용자(최대 100명)만 로그인할 수 있습니다.
   - 두 범위 모두 민감하지 않은 범위라 Google 검수는 필요 없습니다. 앱 로고는 올리지 마세요. 로고를 올리면 브랜드 확인을 받아야 할 수 있습니다.

## 4. OAuth 클라이언트 ID 만들기

1. **Google 인증 플랫폼 → 클라이언트 → 클라이언트 만들기**를 누릅니다.
2. 애플리케이션 유형은 **웹 애플리케이션**입니다. 이름은 아무거나 넣습니다.
3. **승인된 자바스크립트 원본**에 다음 두 개를 넣습니다. 끝에 `/`나 경로를 붙이지 않습니다.
   - `https://shardroom.github.io` (GitHub Pages 주소의 앞부분)
   - `http://localhost:5173` (내 컴퓨터에서 `npm run dev`로 띄울 때)
4. **승인된 리디렉션 URI**는 비워 둡니다. 게임은 팝업 창으로 로그인합니다.
5. **만들기**를 누르면 `1234567890-abc…xyz.apps.googleusercontent.com` 모양의 **클라이언트 ID**가 나옵니다. 복사해 둡니다.
   - 클라이언트 보안 비밀번호(secret)는 쓰지 않습니다. 어디에도 넣지 마세요.

## 5. 저장소에 클라이언트 ID 넣기

1. GitHub 저장소의 **Settings → Secrets and variables → Actions**로 갑니다.
2. **Variables** 탭에서 **New repository variable**을 누릅니다.
3. 이름은 `VITE_GOOGLE_CLIENT_ID`, 값은 4단계에서 복사한 클라이언트 ID입니다.
4. 기본 브랜치에 다음 커밋이 올라가면(또는 **Actions → Test and deploy → Run workflow**로 직접 돌리면) 배포된 게임 첫 화면 오른쪽 위, ⚙ 설정 아래에 "로그인" 버튼이 생깁니다.

내 컴퓨터에서 해 볼 때는 저장소 맨 위에 `.env.local` 파일을 만들고 다음 한 줄을 넣은 뒤 `npm run dev`를 실행합니다. 이 파일은 커밋하지 않습니다.

```
VITE_GOOGLE_CLIENT_ID=1234567890-abc…xyz.apps.googleusercontent.com
```

## 무엇이 저장되나

| 항목 | 내용 | Drive에 어떻게 |
| --- | --- | --- |
| 설정 | GM 선택, 예비 GM, AI 자리별 모델, 이름, 효과음, 연출, 관전 막대 접기 | 그대로 |
| API 키 | GM 키, 예비 GM 키, AI 자리별 키 | 내가 정한 **암호로 잠가서** (AES-GCM, 암호에서 PBKDF2로 만든 키) |
| 게임 | 이어 하기 저장 칸 하나 | 그대로 |

- 암호는 어디에도 저장되지 않습니다. 기기마다 처음 한 번 입력하면 그 기기는 다시 묻지 않습니다.
- 암호를 잊었으면 "암호를 잊었어요 (키 초기화)"를 누릅니다. Drive에 있던 키는 버리고, 그 기기의 키를 새 암호로 잠가 다시 올립니다.
- Google 로그인은 1시간쯤 지나면 끝납니다. 그때는 버튼에 "⚠ 다시 연결"이 뜨고, 한 번 누르면 이어서 저장합니다.

## 문제가 생기면

- **버튼이 안 보임**: 변수 이름(`VITE_GOOGLE_CLIENT_ID`)과 값을 확인하고, 변수를 넣은 뒤에 배포가 한 번 더 돌았는지 확인합니다.
- **`origin_mismatch` 오류**: 4단계의 자바스크립트 원본이 게임 주소의 앞부분(`https://shardroom.github.io`)과 정확히 같은지 확인합니다.
- **`access_denied` 또는 "앱이 테스트 중"**: 3단계 6번(프로덕션으로 푸시)을 했는지 확인합니다.
- **팝업이 안 뜸**: 브라우저가 팝업을 막지 않았는지 확인합니다.

# 화면 디자인 메모

아주 전략적인 체스는 친구들이 나무 테이블에 둘러앉아 GM의 판정을 듣는 자리다. 화면의 모든 장식은 그 테이블 위에 실제로 있을 법한 물건에서 나온다: 호두나무 테이블, 금화, 칼로 새긴 탤리, d20, GM이 써 주는 판정서와 봉랍 인장.

## 색

| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| 호두나무 Walnut | `#21160f` | HUD 패널 바탕 (약간 비침) |
| 양피지 Parchment | `#ecdfc0` | 어두운 바탕 위 글자, 판정서 종이 |
| 먹 Ink | `#2b2119` | 판정서 위 글자, 놋쇠 버튼 글자 |
| 놋쇠 Brass | `#c8963e` | 유일한 강조색: 주 행동, 선택된 도구, 포커스, AP(금화) |
| 봉랍 Wax | `#8c2b23` | 체크, 위험, DC 인장 |
| 펠트 Felt | `#4e8a68` | 성공 (주사위 상자 펠트에서) |

혼돈만은 이 세계 밖의 일이라 보라색(`#8a5bb5`)을 쓴다.

## 글꼴

- 함렛 Hahmlet (가변 세리프): 게임의 목소리. 제목, 차례, GM의 서술과 해석, 숫자(DC, 주사위, 시계).
- 고운돋움: 조작부. 버튼, 입력, 로그 줄, 채팅.
- 나눔손글씨 펜: 테이블 위 메모 낙서(3D)에만.
- 크기 단계: 0.8125 / 0.9375 / 1.125 / 1.375 / 1.75 / 2.5 rem.

## 원칙

- 과감함은 한 곳에만: GM 판정서. 양피지 종이, 선언 인용, GM의 해석, 봉랍 인장에 찍힌 DC, d20 스무 면으로 그린 성공 범위. 나머지 HUD는 조용한 호두나무 패널이다.
- 양피지는 판정서에만 쓴다. 화면 전체를 크림색 종이로 만들면 흔한 기본값이 된다.
- 반경은 위계를 따른다: 종이 4px, 패널 12px, 버튼 8px, 태그는 둥글게.
- 움직임은 하나만: 판정서가 테이블에 내려놓이는 순간. 줄이기 설정을 존중한다.
- AP 보유량은 숫자로 보여 주지 않는다(테이블의 금화와 탤리가 보여 준다). 판정서의 비용은 보여 준다.
- 문구는 사용자 말로, 동사로 끝나게: "주사위 굴리기", "취소 (AP는 그대로)".

## 지금까지 시도한 것 (다음에 다듬을 때 참고)

- 2026-11: 회청색 반투명 패널과 시스템 글꼴을 호두나무, 양피지, 놋쇠 토큰과 함렛·고운돋움으로 바꿨다. 상단 도구 다섯 개를 아이콘 한 줄로 묶었다(좁은 화면은 아이콘만). 차례 표시는 백/흑 돌 모양 원과 함렛 글씨. GM 판정은 양피지 판정서, 봉랍 인장의 DC, d20 스무 면 성공 범위, 금화로 그린 비용. 로그는 GM 서술만 함렛에 놋쇠 세로줄, 차례가 바뀌는 곳은 가는 구분선.
- 처음엔 모든 패널을 양피지로 하려다, 화면 전체가 크림색 종이가 되는 흔한 모양새라 판정서에만 남겼다.
- 함렛은 라틴 대문자가 넓다. 휴대폰 제목은 7.2vw로 줄여야 오른쪽 ⚙와 겹치지 않는다.
- 주사위 결과는 투명도 없이 크기로만 나타나게 했다(프레임이 느린 기기에서 숫자가 안 보이는 순간이 없도록).
- 아직 손대지 않은 곳: 낙서 도구 막대의 이모지 아이콘, GM 설정 창의 세부, 승리 화면 연출.

개인정보처리방침

VERY TACTICAL CHESS (아주 전략적인 체스) · 2026년 11월 21일 시행

VERY TACTICAL CHESS는 브라우저에서 돌아가는 체스 게임입니다. 게임을 만든 사람은 서버를 운영하지 않으며, 플레이어의 정보를 받거나 모으거나 팔지 않습니다. 이 문서는 게임이 어떤 정보를 어디에 두는지 설명합니다.

1. 이 브라우저에 저장하는 것

게임은 다음을 이 브라우저의 저장소(localStorage)에 둡니다. 로그인하지 않으면 이 정보는 이 기기를 떠나지 않습니다(API 키를 쓰는 AI 서비스로 가는 요청은 3번).

  • 설정: 고른 GM과 모델, 예비 GM, AI 자리별 모델, 이름, 효과음, 연출
  • 플레이어가 입력한 AI 서비스의 API 키
  • 이어 하기용으로 저장한 게임 하나
  • 끝낸 게임의 기록(최근 100판): 끝난 날짜, 방식, 결과, 턴 수, GM 이름, 명장면, 선언한 특수 행동

2. Google로 로그인했을 때

로그인은 선택입니다. 로그인하면 게임은 Google에 다음 두 가지 권한만 요청합니다.

  • drive.appdata: 플레이어의 Google Drive 안에 있는, 이 게임 전용 숨은 폴더 하나를 읽고 씁니다. 이 폴더는 Drive 화면에 보이지 않고, 플레이어의 다른 Drive 파일은 보거나 읽을 수 없습니다.
  • email: 어느 계정으로 로그인했는지 화면에 보여 주는 데만 씁니다.

전용 폴더에는 vtc-sync.json 파일 하나를 두고, 1번의 설정, 저장된 게임, 게임 기록을 넣습니다. API 키는 플레이어가 정한 암호로 잠근 뒤에 넣습니다(PBKDF2로 만든 키로 AES-GCM 암호화). 암호는 어디에도 저장되지 않습니다.

이 정보는 플레이어의 브라우저와 Google 사이에서만 오갑니다. 게임을 만든 사람에게는 전달되지 않습니다. Google에서 받은 정보는 다른 기기에서 설정과 게임을 이어 쓰는 데만 사용하고, 광고나 다른 목적으로 쓰거나 남에게 넘기지 않습니다.

Google API에서 받은 정보의 사용과 전송은 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

3. AI 서비스로 보내는 것

GM이나 AI 플레이어로 Claude, OpenAI, Gemini 등 AI 서비스를 고르면, 게임은 플레이어의 브라우저에서 그 서비스로 직접 요청을 보냅니다. 이때 보드 상태, 선언한 특수 행동, 판례, 그리고 플레이어가 입력한 API 키가 함께 갑니다. 이 요청에는 각 서비스의 개인정보처리방침이 적용되고, 사용료는 그 키의 주인에게 청구됩니다.

4. 온라인 대전

온라인 방은 두 브라우저를 직접 연결합니다(WebRTC). 서로를 찾을 때만 PeerJS의 공개 중계 서버를 거칩니다. 상대에게는 게임 상태, 채팅, 방에서 쓰는 이름이 전달되고, API 키는 전달되지 않습니다.

5. 지우는 방법

  • 이 기기: 게임의 ⚙ 설정 → Google 계정 → "이 기기에서 지우고 로그아웃". 또는 브라우저에서 이 사이트의 데이터를 지웁니다.
  • Google Drive: Drive 설정 → 앱 관리 → VERY TACTICAL CHESS → "숨겨진 앱 데이터 삭제".
  • 권한 거두기: Google 계정 → 서드 파티 연결에서 이 게임의 접근을 해제합니다.

Summary in English

VERY TACTICAL CHESS runs entirely in the browser; its developer runs no server and receives no player data. Settings, API keys, one saved game and the records of the last 100 finished games are kept in the browser's localStorage. Signing in with Google is optional. It requests only drive.appdata (the app's own hidden folder in the player's Drive; no other Drive files can be seen) and email (to show which account is signed in). The app stores one file, vtc-sync.json, in that folder: settings, the saved game, the game records, and API keys encrypted with a passphrase only the player knows. This data travels only between the player's browser and Google. It is used only to continue settings and games on another device, and it is never shared, sold or used for ads. The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. AI providers the player chooses receive the board state and actions directly from the browser, with the player's own key. To delete: use "이 기기에서 지우고 로그아웃" in the game, delete hidden app data under Drive settings → Manage apps, and revoke access in the Google Account permissions page. Contact: GitHub issues.

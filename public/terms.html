이용 약관

VERY TACTICAL CHESS (아주 전략적인 체스) · 2026년 11월 21일 시행

1. 서비스

VERY TACTICAL CHESS는 무료로 쓰는 브라우저 게임입니다. 회원 가입이 없고, Google 로그인은 설정과 게임을 내 Google Drive에 보관하고 싶을 때만 씁니다.

2. AI 서비스와 API 키

  • GM과 AI 플레이어는 플레이어가 고른 AI 서비스(Claude, OpenAI, Gemini 등)를 플레이어의 API 키로 부릅니다.
  • 그 사용료와 사용 한도는 키 주인의 몫이고, 각 서비스의 약관을 따릅니다.
  • API 키는 스스로 관리해 주세요. 남의 키를 쓰거나, 서비스 약관을 어기는 방식으로 쓰지 마세요.

3. 지켜 주실 것

  • 온라인 방과 채팅에서 다른 사람을 괴롭히거나 불법적인 내용을 보내지 마세요.
  • 게임을 다른 사람의 기기나 서비스를 공격하는 데 쓰지 마세요.

4. 보증 없음

게임은 있는 그대로 제공됩니다. 오류, 저장된 내용의 손실, AI의 판정, AI 서비스의 요금이나 장애에 대해 게임을 만든 사람은 책임지지 않습니다. 중요한 API 키는 따로 보관해 두세요.

5. 바뀔 때와 문의

약관이 바뀌면 이 페이지를 고치고 위의 날짜를 바꿉니다. 개인정보는 개인정보처리방침을 따릅니다. 문의는 GitHub 이슈로 남겨 주세요.
